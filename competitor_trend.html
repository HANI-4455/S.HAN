투썸플레이스 · 스타벅스 · 메가MGC커피의 신제품과 구글 · 네이버 뉴스 트렌드를 한 화면에서 확인하는 도구입니다.

무엇을 할 수 있나요

신제품 요약(홈)세 브랜드 신제품을 한 번에 수집해 제품 이미지 카드로 모아 보기 · 전체 CSV 다운로드
경쟁사 제품 동향브랜드별 전체 메뉴를 카테고리별로 조회 — 제품명 · 제품 이미지 · 제품 설명(설명 이미지 포함)
뉴스 트렌드키워드 뉴스 검색 후 일자별 기사량 · 연관 키워드 · 주요 언론사 분석, 결과는 카드 뉴스로 정리

내 PC에서 실행하기

  1. 소스 내려받기 — GitHub에서 보기
  2. 필요한 라이브러리 설치 
    pip install -r requirements.txt
  3. 앱 실행 — 브라우저에서 http://localhost:8501 이 열립니다. 
    streamlit run app.py

참고

네이버는 뉴스 검색 RSS를 폐지해, 안정적으로 쓰려면 네이버 검색 Open API 키(무료)를 발급받아 앱 화면에 입력하는 것이 좋습니다. 키가 없어도 네이버 뉴스 검색 결과를 읽어 대체 수집합니다.

수집 결과는 30분간 캐시되며, 각 화면의 실행 버튼을 다시 누르면 새로 수집합니다. 경쟁사를 추가하려면 크롤러 파일 하나를 만들고 app.py의 COMPETITORS 목록에 한 줄만 추가하면 됩니다.
