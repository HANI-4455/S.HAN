# 직영점 폐점 분석 자동화 — 사용 가이드

> 3단계(폐점 비용)는 두 기존 파일을 그대로 자동화했습니다.
> - 「폐점 원복비 실적 입력」: 입지 유형 × 철거 범위별 평당 원복비 적게/보통/많이, 주의 항목, 확정도 등급
> - 「25년 12월 B&S 정산」: 실제 폐점 점포의 원상복구·매몰비 → 브랜드별 건당 평균

## 1. 설치 (5분, 1회만)

1. 새 Google Sheets 파일을 엽니다.
2. **[확장 프로그램 → Apps Script]** 를 클릭합니다.
3. 기본 코드(`function myFunction() {}`)를 모두 지우고 `폐점분석_AppsScript.gs` 내용 전체를 붙여넣은 뒤 💾 저장합니다.
4. (대시보드·챗봇 화면도 `.gs` 파일 안에 들어 있으므로 **HTML 파일을 따로 만들 필요가 없습니다.**)
5. Sheets 화면을 새로고침(F5)하면 상단에 **[🏪 폐점분석]** 메뉴가 생깁니다.
6. **[🏪 폐점분석 → 🛠 시트 만들기 (샘플 데이터 포함)]** 을 실행합니다.
   - 권한 승인 창이 뜨면 계정 선택 → [고급] → [(프로젝트명)으로 이동] → [허용]을 누릅니다.
7. (권장) **[⏰ 매일 자동 갱신 켜기]** 를 한 번 실행합니다. 날짜가 지나면 감가상각과 잔여임차료가 매일 다시 계산됩니다.
8. (챗봇) **[🔑 챗봇 API 키 설정]** 에 Anthropic API 키(`sk-ant-...`)를 한 번 붙여넣습니다. → 10장 참고

> 이미 1~3단계 버전을 쓰고 있었다면 `.gs` 파일 내용만 새 코드로 바꾸면 됩니다. 이전 안내대로 만든 HTML 파일이 있다면 지워도 되고, 그대로 두어도 상관없습니다.
> **[🛠 시트 만들기]** 를 한 번 더 실행하면 [설정]에 새 항목 3개(잔여임차료 반영률, 추세 분석 기간, 감가상각비 포함)가 추가되고, 기존 데이터는 그대로 유지됩니다.

> 샘플 데이터로 동작을 확인한 뒤 샘플 행을 지우고 실제 데이터를 입력하세요.
> 이미 있는 시트는 덮어쓰지 않으므로, **[🛠 시트 만들기]** 를 다시 실행해도 기존 데이터는 그대로입니다.

## 2. 시트 구성

| 시트 | 구분 | 내용 |
|---|---|---|
| **손익현황** | 입력 | 브랜드명·점포명·연월(YYYY-MM)·매출·비용 → 영업이익은 자동 계산 |
| **누적손익** | 자동 (1단계) | 점포별 누적매출/비용/영업이익, 영업이익률, 최근 3개월 평균 |
| **자산투자비** | 입력+자동 (2단계) | 평수·투자비·내용연수·임차정보 입력 → 감가상각누계액·잔존자산가치·잔여임차료가 자동 계산됨 |
| **폐점이력** | 입력+자동 (3단계) | 과거 폐점 원복비 실적. **기존 [실적입력] 시트와 열 순서가 같습니다** |
| **폐점기준값** | 자동 (3단계) | 입지 유형 × 철거 범위별 평당 원복비 적게(최소)/보통(중앙값)/많이(최대), 신뢰도 |
| **폐점검토** | 입력+자동 (3단계) | 폐점 검토 점포의 조건 입력 → 원복비 범위·판단·확정도 등급 (기존 [참고범위]를 여러 점포에 적용) |
| **폐점비용실적** | 입력+자동 (3단계) | 실제 폐점 정산 내역. **기존 B&S 파일 [최종금액] 시트와 열 순서가 같습니다** |
| **브랜드폐점실적** | 자동 (3단계) | 브랜드별 폐점 점포수, 원상복구·매몰비 합계와 건당 평균, 매몰비 비중, 정산 상태 |
| **폐점요약** | 자동 (최종) | 점포별 한 줄 요약 (AI 챗봇 연동용) |
| **브랜드요약** | 자동 (최종) | 브랜드별 합계 |
| **폐점시점분석** | 자동 (4단계) | 점포별 최적 폐점 시점, 권고, 즉시 폐점/계약 만료 운영 대비 이득 |
| **설정** | 입력 | 시트별 금액 단위, 계산 기준일, 최소 사례수, 원복비 적용 수준, 요약 대상 범위 |

- **파란색 제목 열** = 입력하는 열, **회색 제목 열** = 자동으로 채워지는 열입니다. 제목 셀에 마우스를 올리면 입력 방법 메모가 보입니다.
- 입력 시트를 수정하면 **즉시 전체가 다시 계산**됩니다. 직접 갱신하려면 [🔄 원본 가져오기 + 전체 다시 계산]을 누르세요.
- 스크립트는 **제목 이름**으로 열을 찾으므로 열을 추가해도 됩니다. 제목 글자는 바꾸지 마세요.

### 기존 원복비 실적 데이터 옮기기
기존 파일의 **[실적입력] 시트 A5:S(마지막 행)** 를 복사해서 **[폐점이력] A2** 에 **값만 붙여넣기**(Ctrl+Shift+V) 하세요.
P(평당 원복비)·Q(주의 항목 수) 열은 스크립트가 천원 단위로 다시 계산합니다.

### 기존 B&S 정산 데이터 옮기기
B&S 파일의 **[최종금액] 시트 B5:K(마지막 행)** 를 복사해서 **[폐점비용실적] A2** 에 **값만 붙여넣기** 하세요. 단위는 원 그대로 두면 됩니다.
- 소급·정산 차액 행(음수)은 **같은 점포코드끼리 자동 합산**되어 한 건의 폐점으로 계산됩니다.
- 위약금이 따로 있으면 맨 오른쪽 `위약금` 열에 입력하세요. (B&S [최종금액]에서는 원상복구에 포함되어 있음)
- **브랜드 표기를 모든 시트에서 통일하세요.** (예: PB, PAS, PC, CW, LAG, STR, LI) 브랜드 이름이 같아야 폐점요약의 "브랜드 과거 건당" 비교값이 연결됩니다.

**검증:** 실제 B&S 데이터로 돌려 본 결과, 브랜드별 원상복구·매몰비·합계가 기존 [최종금액] M~P열 브랜드 합계와 모두 일치했습니다.

## 3. 계산 기준

| 항목 | 계산식 |
|---|---|
| 영업이익 | 매출 − 비용 |
| 누적손익 | 점포의 전체 월 영업이익 합계 |
| 계산 기준일 | [폐점검토] 폐점예정일 → [설정] 계산 기준일 → 오늘 (앞에 있는 값이 우선) |
| 감가상각누계액 | (인테리어+집기+기타투자비) × 경과개월 ÷ (내용연수×12), 정액법·잔존가치 0 |
| 잔존자산가치 (= 예상 매몰비) | (인테리어+집기+기타투자비) − 감가상각누계액 ※ 보증금은 돌려받는 돈이므로 제외 |
| 잔여임차료 | 월임차료 × 잔여임차개월 (기준일 ~ 임차종료일) |
| 평당 원복비 | 원복 공사비 ÷ 면적(평) |
| 예상원복비 | 평당 원복비(적게/보통/많이) × 평수. 평수가 없으면 브랜드 건당 평균 원상복구 |
| 기타 폐점비 | 과거 전체 사례 평균 (인력 정리·재고 폐기·간판 등) |
| 위약금 | [폐점검토] 위약금_직접입력 |
| **예상폐점비용(원복+매몰)** | 예상원복비([설정] 적용 수준, 기본 보통) + 매몰비(잔존자산가치) |
| **예상총손실액** | 잔여임차료 + 예상폐점비용(원복+매몰) + 기타 폐점비 + 위약금 |
| 폐점 후 최종손익 | 누적손익 − 예상총손실액 (점포 전체 기간 성과, 참고용) |

### 원복비 기준값 적용 규칙 (기존 [참고범위] 시트와 같음)
1. [폐점검토]에 `원복비_직접입력` 값이 있으면 그 금액을 씁니다.
2. `시설 인수 협의 = Y` 이면 철거 범위를 **인수인계**로 보고 계산합니다.
3. 같은 **입지 유형 × 철거 범위** 사례가 **3건 이상**이면 그 사례의 최소/중앙값/최대를 씁니다.
4. 3건 미만이면 **전체 사례** 기준으로 계산합니다. `원복비 적용기준` 열에 사유가 표시됩니다.
5. [폐점검토]에 없는 점포는 입지 정보가 없으므로 전체 사례 기준 × 평수로 계산합니다.
6. 평수가 없으면 [브랜드폐점실적]의 **브랜드 건당 평균 원상복구**를 씁니다. 브랜드 사례가 3건 미만이면 전체 평균을 씁니다.

### 매몰비를 잔존자산가치로 보는 이유
B&S 정산의 매몰비는 231,900,041원처럼 끝자리가 딱 떨어지지 않습니다. 감가상각 후 남은 장부가를 손실 처리한 금액으로 보입니다.
그래서 예상 매몰비는 2단계의 잔존자산가치를 사용하고, 예상총손실액에서 두 번 더하지 않습니다.
폐점요약의 `브랜드 과거 건당 원상복구/매몰비` 열과 비교하면 예상값이 과거 실적과 비슷한지 확인할 수 있습니다.

| 판단 / 등급 | 기준 |
|---|---|
| 판단 | 주의 항목 6개 중 Y가 0개: "적게~보통", 1개: "보통 이상", 2개 이상: "보통~많이" |
| 확정도 C | 원상복구 범위 미확인 → 내부 참고용 |
| 확정도 B | 범위는 확인했으나 현장 실사 전 → 범위로만 보고 |
| 확정도 A | 두 가지 모두 완료 → 참고 범위로 보고 가능 |
| 신뢰도 | 사례 5건 이상: 양호, 3~4건: 참고, 3건 미만: 사례 부족 |

**검증:** 샘플(기존 파일의 가상 18건)로 계산한 결과가 기존 파일의 [기준표]·[참고범위] 결과와 일치합니다.
예) 로드샵·전체 철거 35평: 원복비 14,700 / 18,025 / 33,250천원 (= 1,470 / 1,802.5 / 3,325만원), 기타 폐점비 2,972천원.

## 4. 금액 단위

- 결과는 모두 **천원 단위, 쉼표 형식(#,##0)** 으로 표시되고, 손익이 음수이면 빨간색으로 표시됩니다.
- 입력 단위는 [설정]에서 시트별로 고릅니다 (원 / 천원 / 만원).

| 설정 항목 | 기본값 |
|---|---|
| 손익현황 금액 단위 | 천원 |
| 자산투자비 금액 단위 | 천원 |
| 폐점이력·폐점검토 금액 단위 | **만원** (기존 원복비 실적 파일 기준) |
| 폐점비용실적 금액 단위 | **원** (기존 B&S 정산 파일 기준) |

## 5. 데이터 점검 열

- `중복월 2026-03 (합산됨)` / `누락월 2개`: 손익현황 입력 확인 필요
- `투자시점 누락(상각 미반영)`: 감가상각을 하지 못해 투자비 전액이 잔존가치로 계산됨
- `자산투자비 평수 미입력`: 원복비를 계산할 수 없어 0으로 처리됨
- `자산투자비 미입력` / `손익현황 미입력`: 한쪽 시트에만 있는 점포
- `점포 중복입력(첫 행만 요약 반영)`: 같은 점포가 두 번 입력됨

## 6. 표 구조 (챗봇·외부 연동용)

- `폐점요약`·`브랜드요약`·`폐점기준값`은 **1행 제목 + 2행부터 데이터**로만 이루어져 있습니다. 병합 셀이나 소계 행 없이 점포(또는 유형) 하나가 한 행입니다.
- 금액 열 제목에 `(천원)` 단위를 넣고, 판단·확정도 등급·적용기준을 문장으로 함께 담아 AI가 근거까지 설명할 수 있게 했습니다.

## 7. 알아 둘 점

- 위약금은 `위약금_직접입력`에 넣어야 합계에 반영됩니다. 원복 지연에 따른 추가 임차료는 `기타폐점비_직접입력`에 반영하세요. 보증금 공제는 반영하지 않습니다.
- 잔여임차료와 위약금을 둘 다 입력하면 둘 다 손실로 더해집니다. 중도 해지 시 위약금만 내는 계약이라면 계산 기준일을 조정하거나 판단에 참고하세요.
- B&S 파일의 [창혁자료] 시트(ERP 대비 기획 금액 대사)는 최종 금액이 아니어서 사용하지 않았습니다.
- 인수인계처럼 사례가 적은 유형은 전체 사례 기준으로 계산되어 실제보다 크게 나올 수 있습니다. 기존 파일과 같은 규칙입니다.
- 리뉴얼로 추가 투자가 있었다면 `기타투자비`에 합산해야 합니다. 한 점포당 한 행만 지원합니다.

## 8. 대시보드 (📊 대시보드 열기)

메뉴 **[🏪 폐점분석 → 📊 대시보드 열기]** 를 누르면 시트 위에 큰 창이 열립니다.

| 탭 | 내용 |
|---|---|
| **점포 분석** | 점포를 입력하거나 고르면 **현황**(누적 매출·손익, 최근 3개월 평균, 영업이익 추세, 잔존가치, 잔여 임차, 확정도)이 나옵니다. **폐점 월**을 고르면 그 달 말에 폐점할 때의 예상 비용과 순손익을 보여 줍니다 |
| **전체 점포** | 모든 점포의 최적 폐점 시점과 권고를 한 표로 보여 줍니다. "조기 폐점이 유리한 점포"만 따로 볼 수 있고, 행을 누르면 그 점포의 분석 화면으로 이동합니다 |
| **💬 챗봇** | 대화형 질문 (10장) |

**화면 구성**
- **권고 배너:** 최적 폐점 시점과, 계약 만료까지 운영할 때·즉시 폐점할 때와 비교한 이득
- **선택 월 폐점 카드:** 예상 폐점 비용 합계와 내역(잔여임차료, 매몰비, 원복비, 기타·위약금), 그 달까지의 예상 영업이익, 순손익
- **차트 3개**
  - 폐점 시점별 순손익: 가장 높은 달이 최적 시점이며, 녹색 점선으로 표시됩니다
  - 월별 영업이익 실적(실선)과 전망(점선)
  - 폐점 월별 예상 비용(쌓은 막대)
- **조건 바꿔 보기:** 잔여임차료 반영률(슬라이더), 원복비 수준(적게/보통/많이), 손익 전망(추세 연장/평균 유지)을 바꾸면 화면과 최적 시점이 바로 다시 계산됩니다

**새 탭(전체 화면) 링크로 쓰기 — 권장**
1. Apps Script 편집기 오른쪽 위 **[배포 → 새 배포]** 를 누릅니다. 유형 선택(⚙)에서 **웹 앱**을 고릅니다.
2. 다음 사용자 인증 정보로 실행은 **나**, 액세스 권한은 **조직 내 모든 사용자**(또는 필요한 범위)로 설정합니다. **[배포]** 를 누르고 권한을 허용합니다.
3. 나오는 **웹 앱 URL**이 대시보드 링크입니다. 시트 메뉴 **[🔗 대시보드 새 창으로 열기]** 를 눌러도 이 링크가 열립니다.
   - 링크 끝에 `?mode=chat`을 붙이면 챗봇만 크게 열립니다.
- ⚠ **코드를 바꾼 뒤에는 [배포 → 배포 관리 → ✏ 수정 → 버전: 새 버전 → 배포]** 를 해야 링크에 반영됩니다. URL은 그대로 유지됩니다.
- "나"로 실행하므로, 링크를 연 사람은 배포한 사람의 권한으로 시트 데이터를 보게 됩니다. 액세스 범위는 사내 인원으로 제한하세요.

## 9. 최적 폐점 시점 계산 방법

이번 달부터 계약 종료월까지 **매달 말에 폐점한다고 가정한 경우를 모두 계산**한 뒤 비교합니다. 결과는 [폐점시점분석] 시트에도 정리됩니다.

```
순손익(M월 폐점) = 이번 달 ~ M월 예상 영업이익 합계 − M월 폐점 비용
M월 폐점 비용   = M월 이후 남은 임차료 × 반영률 + 잔존자산가치(매몰비) + 원복비 + 기타 폐점비
                 + 위약금(계약 만료 전에 폐점할 때만)
최적 폐점 시점   = 순손익이 가장 큰 달
```

- **예상 영업이익:** 최근 12개월([설정]에서 변경) 월 영업이익의 직선 추세를 연장합니다. R²(추세 설명력)가 0.3 미만이면 추세가 불확실하다는 뜻이니 "평균 유지"로도 확인하세요.
- **잔여임차료 반영률이 결론을 크게 좌우합니다.**
  - 100%(남은 임차료 전액 부담)이면 일찍 닫아도 임차료를 아끼지 못하므로, 임차료를 내기 전 기준으로도 적자인 점포만 조기 폐점이 유리해집니다.
  - 건물주와 위약금으로 협의할 수 있다면 반영률을 낮추고 위약금을 [폐점검토]에 입력해 다시 비교해 보세요.
  - 예) 샘플 신촌점: 반영률 100%면 최적 시점이 2027-04이고, 50%면 즉시 폐점이 유리합니다.
- **감가상각비:** [손익현황]의 비용에 감가상각비가 포함되어 있다고 가정합니다. 포함되어 있지 않다면 [설정]에서 `손익에 감가상각비 포함 = N`으로 바꾸세요.
- **한계:** 이 값은 추세를 단순 연장한 추정치입니다. 계절성, 상권 변화, 리뉴얼 효과는 반영하지 않습니다.

## 10. 챗봇 (💬)

대시보드의 **💬 챗봇 탭**이나 메뉴 **[💬 챗봇 열기]**(오른쪽 사이드바)에서 질문합니다.

**질문 예시**
- "신촌점 언제 폐점하는 게 가장 좋아? 근거랑 가정도 알려줘"
- "조기 폐점이 유리한 점포를 표로 정리해줘"
- "판교점을 2027년 3월에 닫으면 비용이 얼마야?"
- "잔여임차료를 50%만 내도 된다면 결론이 바뀌는 점포는?"
- "PB 브랜드 과거 폐점 비용 평균은?"

**작동 방식**
- Claude(Anthropic의 AI, 모델: Claude Opus 5.5)가 시트 데이터를 **도구로 직접 조회·계산**해서 답합니다. 숫자를 지어내지 않도록, 계산은 대시보드와 같은 함수로 합니다. 답변 위에 어떤 조회를 했는지 🔎 표시가 나옵니다.
- 쓰는 도구: 점포 목록, 점포 상세, 특정 월 폐점 시뮬레이션, 최적 시점 계산, 브랜드별 폐점 실적(B&S), 원복비 기준값
- 안전 필터에 걸리면 다른 모델로 자동 재시도합니다.

**API 키 준비**
1. [console.anthropic.com](https://console.anthropic.com)에서 회사 계정으로 API 키를 발급받습니다.
2. 시트 메뉴 **[🔑 챗봇 API 키 설정]** 에 붙여넣습니다.
   - 키는 스크립트 속성에만 저장되고 시트에는 표시되지 않습니다.
   - 스크립트 편집 권한이 있는 사람은 키를 볼 수 있으니, 편집 권한은 담당자에게만 주세요.
3. 사용량에 따라 API 요금이 나옵니다. 질문 한 번에 보통 2~4번의 API 호출이 일어납니다.

**보안:** 질문 내용과 조회된 점포 데이터는 Anthropic API로 전송됩니다. 사내 공유 기준으로 사용해 주세요.

**설정 바꾸기 (코드 상단 상수)**

| 상수 | 기본값 | 의미 |
|---|---|---|
| `CLAUDE_MODEL` | `claude-opus-5-5` | 사용할 모델 |
| `CLAUDE_EFFORT` | `low` | 답변 깊이. `medium`/`high`로 올리면 더 깊이 분석하지만 느리고 비용이 늘어납니다 |
| `CHAT_MAX_TOOL_ROUNDS` | 8 | 한 질문에 연달아 조회할 수 있는 최대 횟수 |

**새 대화:** 대화가 길어지면 답이 느려지고 비용이 늘어납니다. 주제가 바뀌면 챗봇 아래의 **[새 대화]** 를 누르세요.

## 11. 원본 시트(직영점 데이터) 연동

손익 데이터를 붙여넣지 않고, 기존 **직영점 데이터 구글 시트를 그대로 읽어 오게** 할 수 있습니다. 원본 시트는 읽기만 하고 고치지 않습니다.

**설정 방법**
1. 폐점분석 시트 [설정]의 **원본 시트 주소**에 직영점 데이터 시트 주소를 붙여넣습니다.
2. 메뉴 **[🏪 폐점분석 → 🔄 원본 가져오기 + 전체 다시 계산]** 을 누릅니다. 처음에는 다른 파일을 읽는 권한을 허용해야 합니다.
3. 이후에는 매일 자동 갱신(오전 6시) 때도 원본을 다시 가져옵니다.

| 원본 탭 | 가져오는 곳 | 내용 |
|---|---|---|
| **시트3** (월별 손익, 원) | [손익현황] | 매출 = 순매출액, 이익 = [설정]의 **손익 기준 이익** (기본 점포이익), 비용 = 매출 − 이익. 천원으로 환산 |
| **점포정보** | [자산투자비] | POS코드로 찾아 **평수·투자시점(오픈일)** 을 빈 칸에만 채웁니다 |
| **폐점비** (천원) | [폐점비용실적] | 원상복구·매몰비. 기존 정산 표시(○/△)는 유지됩니다 |

- **폐점한 점포는 자동으로 뺍니다.** 폐점비 탭에 있거나, 가장 최근 달 손익이 없는 점포가 대상입니다.
- **브랜드**는 점포명 앞머리(PB·PC·LAG·STR…)나 소속(파스쿠찌 등)으로 추정합니다. 틀리면 [브랜드매핑] 시트의 C열에 직접 지정하고 다시 가져오세요.
- **손익 기준 이익:** 폐점 판단에는 **점포이익**을 권장합니다. 본부·사업부 배부 비용은 점포를 닫아도 남기 때문입니다. [설정]에서 사업부이익·영업이익으로 바꿀 수 있습니다.
- **원본에 없는 정보는 직접 입력해야 합니다.** 인테리어·집기 투자비, 내용연수, 보증금, 임차종료일, 월임차료가 해당하며, [자산투자비]에서 해당 점포 행에 넣으면 됩니다. 다시 가져와도 직접 입력한 값은 지워지지 않습니다. 입력 전에는 잔존가치·잔여임차료가 0으로 계산되고, 데이터점검에 표시됩니다.
- 처음 가져올 때 시트를 만들며 넣었던 '샘플 ○○점'은 자동으로 지워집니다.
- 셀을 고칠 때 자동으로 도는 계산은 원본을 가져오지 않습니다(구글 제한). 원본이 바뀌었으면 수동 갱신을 누르세요.
