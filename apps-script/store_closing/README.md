# 직영점 폐점 분석 (구글시트 연동판) — Apps Script 소스

이 폴더는 **웹 페이지가 아니라 소스 보관용**입니다. 실제 화면은 구글 시트에 붙은 Apps Script 웹 앱 주소로 엽니다.
허브의 "직영점 폐점 분석" 카드가 그 주소로 연결됩니다.

| 파일 | 넣는 곳 |
|---|---|
| `Code.gs` | Apps Script 편집기의 `Code.gs` (대시보드·챗봇 화면 HTML도 이 파일 안에 들어 있음) |
| `설치_안내.md` | 설치·웹 앱 배포·계산 기준·챗봇 API 키 설정 방법 |

**주요 기능**
- 1단계: 월별 손익 → 점포별 누적손익
- 2단계: 투자비·임차 정보 → 감가상각, 잔존자산가치, 잔여 임차료
- 3단계: 과거 원복비 실적(입지 유형 × 철거 범위 평당 단가)과 B&S 폐점 정산 → 예상 폐점비용, 폐점요약
- 4단계: 영업이익 추세 기반 최적 폐점 시점 + 대시보드(점포 현황, 월별 폐점 비용 시뮬레이션)
- 5단계: Claude API 챗봇 (시트 데이터를 도구로 조회·계산)

**데이터 관리**
- 이 폴더에는 점포 손익·정산 데이터가 없습니다. 샘플은 모두 가상 데이터입니다. 실제 데이터는 구글 시트에만 넣고, **이 저장소에는 올리지 않습니다.**
- 챗봇 API 키는 코드에 없고 Apps Script 스크립트 속성에만 저장됩니다.
- 코드를 고쳤으면 이 폴더도 같이 갱신해 두세요. 웹 앱은 **[배포 관리 → 수정 → 새 버전]** 을 해야 반영됩니다.
