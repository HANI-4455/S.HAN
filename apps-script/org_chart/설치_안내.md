# 조직도 관리 — 구글시트 연동판 설치 안내

대상: 사업지원팀 조직도 원본 구글 시트 (시트 주소는 담당자에게 받으세요)
넣을 파일: 이 폴더의 `Code.gs`, `Index.html` 두 개. 전체 20분 정도 걸립니다.

## 권한 구조 한눈에 보기

| 누가 | 어떻게 들어오나 | 할 수 있는 것 |
|---|---|---|
| 모든 직원 | 웹 앱 주소 클릭, 로그인 없음 | 확정된 조직도 보기, 과거 기준일 조회, 변동 내역, 사람별 이력, 인쇄 |
| 관리자 | 화면 오른쪽 위 [관리자 로그인] | 위 기능 + 명단 수정, 기준일 확정·삭제, 설정, 관리자 계정 관리 |
| 시트 편집자 | 구글 시트 직접 | 데이터 탭 직접 수정, 코드 수정·재배포, admin 비밀번호 초기화 |

- 관리자 비밀번호는 코드에 없고, Apps Script 스크립트 속성에 해시로만 저장됩니다.
- 로그인은 6시간 유지되고, 5번 틀리면 10분 동안 잠깁니다.
- 화면은 배포한 사람의 권한으로 시트를 읽기 때문에, 직원들에게 시트를 공유할 필요가 없습니다. 시트는 관리자만 볼 수 있게 잠가 두세요.
- 주의: 웹 앱 주소를 아는 사람은 누구나 명단을 볼 수 있습니다. 주소는 사내에만 공유하세요.

## 0. 백업

시트에서 **파일 > 사본 만들기**. 사본에는 기존 Apps Script도 같이 복사됩니다.

## 1. 코드 넣기

1. 시트 메뉴 **확장 프로그램 > Apps Script**
2. 왼쪽 톱니바퀴 **프로젝트 설정** → "Chrome V8 런타임 사용 설정" 체크 확인
3. **편집기(<>)** 에서 기존 `.gs` 파일 내용을 모두 지우고 `Code.gs` 붙여넣기. 예전 조직도 스크립트 파일이 따로 있으면 삭제
4. **파일 추가(+) > HTML** → 이름 `Index` → 내용을 지우고 `Index.html` 붙여넣기
5. 저장 (Ctrl+S)

## 2. 초기 설정과 첫 관리자 계정

1. 함수 선택에서 `setup` → **실행**
2. 권한 검토 → 본인 계정 → "Google에서 확인하지 않은 앱" 화면에서 **고급 > (프로젝트 이름)(으)로 이동 > 허용**. 배포하는 사람 한 명만 합니다.
3. 아래쪽 **실행 로그**에 나오는 `admin` 임시 비밀번호를 적어 둡니다.
4. 시트에 `조직도_이력`, `조직도_기준일정보`, `조직도_설정` 탭이 생겼는지 확인

## 3. 웹 앱 배포

1. **배포 > 새 배포** → 유형 **웹 앱**
2. 다음 사용자 인증 정보로 실행: **나** / 액세스 권한이 있는 사용자: **모든 사용자**
3. **배포** → 웹 앱 URL 복사 → 허브 조직도 카드에 연결

## 4. 과거 이력 가져오기 (처음 한 번, 해당될 때만)

이관용 CSV는 담당자 PC에만 있습니다. **조직도_이력** 탭과 **조직도_기준일정보** 탭에서 각각 **파일 > 가져오기 > 업로드** → 현재 시트 바꾸기 → "텍스트를 숫자, 날짜, 수식으로 변환" 체크 해제.

## 5. 첫 사용

1. 웹 앱 주소 → **관리자 로그인** → `admin` / 임시 비밀번호
2. **설정 > 관리자 계정**에서 내 비밀번호를 바꾸고, 편집할 사람을 관리자로 추가
3. **인원 편집**에서 명단과 점검 항목을 정리한 뒤 왼쪽 **기준일 확정**
4. **인쇄 / PDF** 로 A4 가로 한 장 확인

## 6. 시트 공유 정리

시트 **공유** → 일반 액세스를 **제한됨**으로, 공유 목록에는 시트를 직접 관리할 사람만 편집자로 둡니다. 웹 앱 화면은 계속 열립니다.

## 7. 코드를 고친 뒤 반영

**배포 > 배포 관리 > 연필 > 버전: 새 버전 > 배포**. 주소가 유지됩니다. "새 배포"를 만들면 주소가 바뀝니다.

## 8. 인수인계

1. 설정 탭에서 후임자를 관리자로 추가하고, 떠나는 사람 계정은 후임자가 삭제
2. 후임자에게 시트 편집 권한, 필요하면 소유권 이전
3. 웹 앱은 배포한 사람 계정으로 실행됩니다. 배포한 사람이 떠나기 전에 후임자가 3단계를 다시 해서 새로 배포하고 허브 카드 주소를 바꿉니다.
4. 관리자 비밀번호를 모두 잊었으면 시트 편집자가 시트 메뉴 **조직도 관리 > admin 비밀번호 초기화** 실행
