# 조직도 관리 (구글시트 연동판) — Apps Script 소스

이 폴더는 **웹 페이지가 아니라 소스 보관용**입니다. 실제 화면은 구글 시트에 붙은 Apps Script 웹 앱 주소로 엽니다.
허브의 "조직도" 카드가 그 주소로 연결됩니다.

| 파일 | 넣는 곳 |
|---|---|
| `Code.gs` | Apps Script 편집기의 `Code.gs` |
| `Index.html` | Apps Script 편집기의 HTML 파일 `Index` |
| `설치_안내.md` | 설치·배포·관리자 계정·인수인계 방법 |

- 이 폴더에는 명단이나 이력 데이터가 없습니다. 데이터는 구글 시트에만 있고, **이관용 CSV 같은 명단 파일은 이 저장소에 올리지 않습니다.**
- 관리자 비밀번호는 코드에 없고 Apps Script 스크립트 속성에 해시로만 저장됩니다.
- 코드를 고쳤으면 이 폴더도 같이 갱신해 두세요. 후임자는 여기서 최신 코드를 받습니다.
